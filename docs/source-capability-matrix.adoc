= Source capability matrix
v1.0 (2026-10-20)

What each SDO source can do for Relaton: **enumerate** the corpus, **enrich**
per-document fields, **fetch** the document, and carry **publication stages**
(drafts, iterations, withdrawn editions). The matrix drives ingestion
decisions: a source that cannot enumerate cannot seed a dataset, and a source
that does not carry stages cannot be the authority for them (NIST's two-source
split is the worked example).

Method: a static audit of each flavor's `DataFetcher` and its parser, on the
date above. It records what the code establishes, not what a live probe
observed; entries marked *unverified* are code-silent. Re-probe before
trusting a source for a new dataset.

== Fragility notes

The `core` flavor is the abstract `Core::DataFetcher` base class and has no
source of its own.

* **CIE** — Cloudflare challenge; stealth headless Chrome (Ferrum), per-worker
  pacing, 4 retries. The browser path is the in-repo precedent for a
  JS-rendered source.
* **ETSI** — PHP `Array` text can replace JSON; deferred page retries; WAF
  rejects non-browser clients (Mechanize UA required).
* **IEC** — OAuth credentials (`IEC_HAPI_PROJ_PUBS_KEY`/`SECRET`); a non-200
  page warns and stops.
* **ITU** — F5 WAF needs a browser UA; ITU-R `/rec` 503 / `/pub` 302 when
  paced too fast (0.4 s tripped it, 1 s is safe); shared Pacer + Governor.
* **NIST** — the GitHub `latest/download` redirect is resolved and logged so a
  crawl proves which release it read; the CSRC zip is cached up to a day.
* **OASIS** — Cloudflare; the challenge wait returns after 30 s without
  raising, so a blocked run can look thin.
* **Plateau** — the Next.js build id (`1.3.0`) is hardcoded; a rebuild upstream
  silently returns `{}`.
* **W3C** — Cloudflare 429/403; pool-wide Governor (60 s growing to 900 s).
* **3GPP** — HEAD must succeed and the CSV must exceed 20 MB; 5 retries.
* **CalConnect, ECMA, JIS, XSF, OGC** — completeness is trusted from the
  listing/JSON; there is no total-count guard.

== Completeness guards

Flavors that can prove they enumerated everything: CIE (next-page link and
per-page count), ETSI (`total_count`), IEC (`Link` rel=last), W3C (abort on
incomplete pagination), IETF (index XML). The rest trust the source listing;
an ingestion health check should compare published row counts against the
previous run for these.

== Uncertainties

* ISO: whether draft-stage deliverables appear in the JSONL is not evident in
  the fetcher (stage codes are).
* 3GPP: whether the CSV carries draft versions is not evident.
* IEC: the pagination stop condition is code-established but not live-verified.
* IEEE IDAMS `docstatus` vocabulary and rawbib draft coverage are not
  enumerated.
* BIPM, JCGM, IANA, IEEE, IETF-internet-drafts read local checkouts, so their
  completeness is bounded by the checkout, not by a remote authority.
