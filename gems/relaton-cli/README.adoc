= relaton-cli

The relaton-cli gem is now a compatibility shell. The Relaton CLI was
consolidated into the https://github.com/relaton/relaton[relaton gem]
(`lib/relaton/cli`), which ships the `relaton` executable and every
`relaton/cli` require path the standalone gem used to provide.

Install the relaton gem directly:

----
gem install relaton
----

Existing bundles that depend on `relaton-cli` keep resolving: this gem
pulls `relaton` as its runtime dependency, and `require "relaton-cli"`
continues to work.
