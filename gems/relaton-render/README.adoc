= relaton-render

The relaton-render gem is now a compatibility shell. Relaton citation
rendering was consolidated into the https://github.com/relaton/relaton[relaton
gem] (`lib/relaton/render`).

Install the relaton gem directly:

----
gem install relaton
----

Existing bundles that depend on `relaton-render` keep resolving: this gem
pulls `relaton` as its runtime dependency, and `require "relaton-render"`
continues to work.
